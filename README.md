# AI美食聊天機器人
### 專案簡介
- 本專題旨在打造一個專為本校學生設計的台南美食聊天助理,協助同學以最自然,最直覺的方式快速探索校園周邊餐廳。為達成此目標,本專題規劃以下功能與技術實作面向:
- 本系統提供之使用方式:用戶可透過時間過濾，地理過濾，相似度檢索之過濾查詢餐飲店家之功能。
1. 建置專屬於本校學生的台南美食資料庫以Google Maps為主要資料來源，整理校園一公里內的餐廳資訊。
- 使用 MySQL 建立餐聽硬資訊的資料庫
   - 店名，地址，評分，連絡電話，營業時間，經緯度，原始評論，評論摘要。
- 使用 Qdrant 建立餐聽軟資訊的資料庫
   - 店家id(查詢MySQL使用)，菜系，食物種類，口味，氣氛，服務標籤，設施標籤，評論摘要。
2. 以單一 LLaMA 模型作為核心語意理解引擎本專題不使用傳統 NLP 模組分工，而是透過 redhat/qwen3.5-9b(MCP模型)，在開發的模型任務流程中完成之功能如下：
   - 中文自然語言理解 --> 使用者意圖辨識 --> 槽位抽取與邏輯樹生成（如食物類型、預算、距離、限制條件等)　--> 對話上下文理解 --> 多輪對話管理
   - 透過此架構之設計可使整體系統架構更簡潔，也讓回應更加一致、自然。
3. 建立自然對話式的美食推薦流程讓使用者能以一般口語方式詢問，如
   -「想吃便宜的」
   -「幫我找學校附近 10 分鐘內的咖哩」
   -「第二家可以預約嗎？」
   - 模型會主動釐清資訊不足之處並提出補問。
   - 回應內容會依照對話歷史進行智能調整，完整呈現多輪對話能力。
4. 完成資料查詢、推薦與格式化輸出後端 API 根據 redhat/qwen3.5-9b 抽出的槽位查詢資料庫。生成各家店的詳細評論摘要並由全域資料連結控制中樞子系統整理成卡片式回覆格式，如：
   - 店名，評分，地址與距離，菜系，食物種類，店家類型，營業時間，店家評論摘要
   - 透過本RAG架構讓介面子系統可直覺呈現美食資訊。
5. 完成系統部署並提供可展示的完整 Demo
   - 使用Docker Compose部屬 全域資料連結控制中樞子系統、MySQL、Qdrant、混和式檢索子系統、智慧Agent與MCP工具服務整合子系統。
   - 讓介面子系統能穩定連線、發出查詢、接收推薦並展示結果。
   - 展示從「語意理解 → 查詢 → 回覆生成」的完整 AI 美食推薦流程。
6. 本專案之資料來源為:Google Place API。若需要資料進行資料庫部屬請聯絡管理員(shawnhuang125)!!!

# GastroBot - APP UI 介面

**本專案之行動終端完全基於 Kotlin 原生語言開發，全面採用 Google 的 Jetpack Compose 響應式 UI 框架，我們的核心目標是建構一個高性能、零延遲且極具互動感的 AI 美食導覽介面**
**為打造最極致的使用者體驗，本專案在 UI 與架構設計上具備以下核心特色：**
- **流暢的互動手勢：導入物理按壓特效、雙指流暢縮放相片牆，並結合直覺的向左滑動刪除與長按拖曳分類功能，讓初次使用的用戶也能快速上手**
- **資料視覺化：聊天介面採用雙向對齊排版，清晰區分對話來源，並將繁雜的後端回覆資訊，動態轉化為文字結構清晰、重點一目了然的排版與「商店摘要卡片」，降低閱讀疲勞**
- **零等待體驗：透過背景預先處理圖文資料，讓使用者在點擊任何店家與切換畫面時，都能感受到如同翻書般的瞬間開啟體感**
- **專屬個人的美食收藏清單：提供高度客製化的「我的收藏」管理介面，使用者可自由定義分類圖示與顏色，打造視覺豐富且井然有序的私藏清單，並將最喜愛的店家收藏至此**

---

## 優勢與架構
- **原生 Kotlin 開發：發揮 APP 極致執行效能與相容性**
- **通訊架構 (HTTP & Socket):**
  - **即時反饋：透過 Socket.IO 建立即時通訊管道，達成與後端建立即時、穩定的通訊協定**
  - **情境感知：結合 HTTP 請求 並動態注入 SID 與 GPS 參數，實現針對當前地理位置的個性化資料檢索，確保回傳內容具備高相關性與精準距離**
- **永久儲存收藏資料：Android Room 資料庫**
  - **持久化安全：採用官方 Room (SQLite) 實作，資料直接寫入手機底層硬碟，即使 App 關閉或裝置重啟，資料夾與收藏內容仍保持 100% 完整**
  - **響應式同步：利用 Kotlin Flow 監聽硬碟異動，資料一變動、畫面立刻重畫，達成「資料與視圖同步」的最高穩定性架構**
- **體感快取體驗:資料預下載**
  - **結合 RAM 快取，並透過 Coil 立即在背景執行將商店圖片預下載，讓詳細頁面點開就是零延遲的秒開體驗**
- **個人化美食推薦標籤：Top3 智慧推薦菜系種類運算**
  - **系統會在背景記錄使用者點擊過的店家菜系標籤寫入 Room 資料庫，並在背景運算過去 14 天的歷史偏好，於首頁即時生成專屬的 Top 3 快速推薦按鈕**

##  開發環境需求
- **Android Studio：Android Studio Rabbit 1 | 2026.2.1**
  - **Kotlin：2.0.21**
- **Android Emulator：Pixel 10 Pro(最低相容版本 Android 12、API 31)**

---

## Android Studio 開啟專案

### 1. 下載專案
- **從GitHub倉庫下載完整Code，或是將專案壓縮檔解壓縮**

### 2. 開啟專案
- **在 Android Studio 中選擇 Open 並指向專案根目錄**

### 3. Gradle 同步
- **點擊頂部的 Sync Project with Gradle Files 圖示
系統會自動下載所有依賴套件**
  - **注意：同步過程需保持網路連線**

### 4. 專案運行
 - **開啟手機模擬器，在 Android Studio 工具列頂部，確認左邊下拉選單是啟動的「虛擬機名稱」，右邊選單是 :app ，點擊頂部的綠色 Run 按鈕**
---

### 運行監控
- **在 Android Studio IDE 左下角，有一個 Logcat (像貓咪的Icon)，點擊後確認上面的下拉選單是選擇當前的 Android 虛擬手機
，並在過濾搜尋框中輸入 Logs，即可快速篩選並檢視本專案的所有Log**

---

## APK 安裝  (使用實體手機 或 Android 虛擬手)
### 1. 下載專案 APK
從 Google 專題資料夾，APK File 將 APK 檔下載下來並解壓縮

 - **如果是實體手機**
   - 直接點開解壓縮後的 APK 檔即可安裝
     
   <br>
   
 - **如果是 Android 虛擬手機**
   - 將解壓縮後的APK檔，拖曳到虛擬手機內，即可安裝

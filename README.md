# 美食聊天機器人
## **專案介紹**

- 本專題旨在打造一個 專為本校學生設計的台南美食聊天助理，協助同學以最自然、最直覺的方式快速探索校園周邊餐廳。為達成此目標，本專題規劃以下功能與技術實作面向：

1. 建置專屬於本校學生的台南美食資料庫以 Google Maps 為主要資料來源，整理校園一公里內的餐廳資訊。包含店名、評分、評論、營業時間、菜系、地址、類型等欄位。使用 MySQL 建立結構化資料庫，提供後端穩定查詢能力。
2. 以單一 LLaMA 模型作為核心語意理解引擎本專題不使用傳統 NLP 模組分工，而是透過 一個微調後的 LLaMA 模型，在單一步驟中完成：
- 中文自然語言理解
- 使用者意圖辨識
- 槽位抽取（如食物類型、預算、距離、限制條件等)
- 錯字修正與語意推斷
- 對話上下文理解
- 多輪對話管理
- 使整體系統架構更簡潔，也讓回應更加一致、自然。
3. 建立自然對話式的美食推薦流程讓使用者能以一般口語方式詢問，如
-「想吃便宜的」
-「幫我找學校附近 10 分鐘內的咖哩」
-「第二家可以預約嗎？」
- 模型會主動釐清資訊不足之處並提出補問。
- 回應內容會依照對話歷史進行智能調整，完整呈現多輪對話能力。
4. 完成資料查詢、推薦與格式化輸出後端 API 根據 LLaMA 抽出的槽位查詢資料庫。將查詢結果整理成 卡片式回覆格式，如：
- 店名
- 評分
- 地址與距離
- 菜系
- 食物種類
- 店家類型
- 營業時間
- 店家評論
- 讓前端 App 可直覺呈現美食資訊
